# 俄羅斯方塊（組合語言版）

這是一個完全用 **ARM64 組合語言**寫成的俄羅斯方塊，可以在 Apple 晶片（M 系列）的 Mac 上玩。
遊戲有兩個版本：

- **終端機版**：在「終端機」App 裡面玩，方塊是用彩色的字元畫出來的。
- **視窗版**：會另外開一個視窗，畫面比較漂亮，用法跟一般的 Mac App 一樣。

兩個版本共用同一套遊戲規則，只有「畫面怎麼畫」和「按鍵怎麼讀」不一樣。

## 需要什麼

- 一台 Apple 晶片的 Mac（M1、M2、M3……都可以）。舊款的 Intel Mac 沒辦法執行，因為兩種晶片的組合語言不一樣。
- Xcode 命令列工具。它提供把組合語言變成程式的 `clang`。還沒裝過的話，在終端機輸入下面這行，照著畫面指示安裝：

  ```bash
  xcode-select --install
  ```

## 編譯

在終端機進入這個資料夾，執行：

```bash
./build.sh
```

完成後，資料夾裡會多出兩個程式：`tetris`（終端機版）和 `tetris_window`（視窗版）。
之後只要改了任何一個 `.s` 檔，就再執行一次 `./build.sh`。

## 開始玩

**終端機版：**

```bash
./tetris
```

終端機視窗請開大一點，至少 24 行高、60 字寬，畫面才放得下。

**視窗版：**

```bash
./tetris_window
```

請從終端機執行。在 Finder 裡直接點兩下也能開，但系統會另外開一個終端機視窗掛在後面。

## 操作方式

| 按鍵 | 功能 |
|---|---|
| ← | 往左移動 |
| → 或 D | 往右移動 |
| ↑ 或 W | 旋轉 |
| ↓ 或 S | 加速往下 |
| 空白鍵 | 直接掉到底 |
| P | 暫停／繼續 |
| A | 打開／關掉自動遊玩 |
| R | 重新開始（只有視窗版） |
| Q | 離開 |
| Ctrl-C | 離開（終端機版） |
| ⌘Q 或按視窗的紅色按鈕 | 離開（視窗版） |

旋轉時如果卡到牆壁或其他方塊，遊戲會自動往左右挪一兩格再試一次。

## 自動遊玩

按一下 **A**，電腦就會替你玩；再按一下就還給你。開著的時候，畫面右邊會顯示「自動遊玩中」。

電腦每拿到一個新方塊，會把「每一種方向 × 每一欄」都試放一次，看放下去之後的場地長什麼樣子，再挑最好的那一個。
它判斷「好不好」看四件事：整體疊得多高、能消掉幾行、有沒有留下蓋住的空洞、表面平不平。
這套打分方法參考了 Yiyuan Lee 公開的俄羅斯方塊 AI。

選好位置之後，電腦會每 0.06 秒做一個動作：先轉方向、再左右移動、最後直接落下，所以你看得到它怎麼放。
實際測試時，它 30 秒大約消掉 36 行、升到第 4 級，場地一直維持在很低的高度。

幾件要知道的事：

- 電腦只看目前這個方塊，不會參考「下一個」。
- 等級很高、方塊掉得很快時，電腦可能來不及移到它選好的位置。
- 自動遊玩開著時你還是可以按方向鍵，但電腦會繼續往它選好的位置移動。
- 按 R 重新開始或遊戲結束，都不會自動關掉它。

## 計分方式

- 一次消掉 1、2、3、4 行，分別得到 100、300、500、800 分，再乘上目前的等級。等級越高，消行越值錢。
- 按 ↓ 加速時，方塊每往下一格加 1 分。
- 按空白鍵直接掉到底時，每掉一格加 2 分。
- 從第 1 級開始，每消 10 行升一級。第 1 級方塊每 0.5 秒往下掉一格，每升一級快 0.05 秒，最快是每 0.05 秒一格。

## 檔案說明

| 檔案 | 內容 |
|---|---|
| `tetris_core.s` | 遊戲規則：方塊怎麼移動、旋轉、消行、算分、升級，還有自動遊玩的電腦。兩個版本共用。 |
| `tetris.s` | 終端機版的畫面與按鍵。 |
| `tetris_window.s` | 視窗版的畫面與按鍵。 |
| `tetris_common.inc` | 三個檔共用的設定，例如場地大小。 |
| `build.sh` | 一次編譯兩個版本的腳本。 |

每個 `.s` 檔最後面都有一段 `AI-NOTES`，記錄寫這個檔時查到的系統數值和踩過的坑。想改程式之前可以先看看。

## 它是怎麼做到的

**遊戲規則（`tetris_core.s`）**
場地是 10 欄 × 20 列，一格用一個位元組記錄：0 是空格，1 到 7 是已經固定下來的方塊。
每一種方塊的每一個方向，都存成一個 4×4 的小圖，剛好用一個 16 位元的數字就能表示。
判斷方塊能不能移動時，就是把這 16 格一格一格拿去跟場地比對，看有沒有撞到牆或其他方塊。

**終端機版（`tetris.s`）**
平常終端機要等你按 Enter 才會把整行字交給程式。這個版本會先把終端機切換成「每按一個鍵就立刻送出、而且不在畫面上顯示」的模式，離開時再改回原本的樣子。
畫面是用終端機的控制碼畫的，例如把游標移回左上角、換背景顏色。整個畫面會先組好，再一次寫出去，這樣畫面才不會閃。

**視窗版（`tetris_window.s`）**
蘋果的視窗系統（Cocoa）是用 Objective-C 寫的。在組合語言裡，要叫 Cocoa 做任何事，都是呼叫同一個 C 函式 `objc_msgSend`，再告訴它「要叫哪個物件、做哪件事」。
遊戲畫面是一個在程式執行時才造出來的類別 `TetrisView`，它負責畫畫面的方法和接收按鍵的方法，都是這個檔裡的組合語言。
另外有一個每 10 毫秒響一次的計時器，負責讓方塊往下掉。

## 寫 Mac 組合語言要注意的地方

- **名字前面要加底線。** C 的 `main` 在組合語言裡要寫成 `_main`，呼叫系統函式也一樣，例如 `_write`、`_usleep`。
- **不要照 Linux 的教學抄。** 網路上很多組合語言教學是寫給 Linux 或 Intel 晶片的，系統數值和呼叫方式都不一樣，照抄通常會出錯。
- **不要用 `printf` 印數字。** 在 Apple 晶片的 Mac 上，`printf` 這種「參數數量不固定」的函式，參數要放的位置跟一般函式不一樣。照一般寫法會印出亂碼，所以這個專案的數字都是自己轉成文字的。
- **堆疊要對齊 16 個位元組。** 每次呼叫別的函式之前，堆疊的位置都必須是 16 的倍數，不然程式會當掉。

## 已知的限制

- 還沒單獨測試過：旋轉卡牆時的自動挪位、升級後的變快。
- 還沒有連續玩很久的測試紀錄。
- 視窗版還不是正式的 `.app`，所以選單列會顯示 `tetris_window`，圖示也是系統預設的。
